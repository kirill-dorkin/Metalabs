## Уроки

1. Backend, HTTP, REST — понимает клиент-серверную модель.
2. NestJS структура — создаёт module/controller/service.
3. DTO и валидация — проверяет входящие данные.
4. PostgreSQL основы — создаёт таблицы и связи.
5. Prisma schema/migrations — работает с ORM.
6. CRUD API — делает создание, чтение, обновление и удаление.
7. Авторизация и JWT — реализует регистрацию и вход.
8. Guards и роли — ограничивает доступ.
9. Pagination/filter/search — делает нормальные API-списки.
10. Ошибки и response format — возвращает понятные ошибки.
11. Тестирование API — проверяет API через Postman/Thunder Client.
12. Мини-проект и экзамен — делает backend для приложения.
