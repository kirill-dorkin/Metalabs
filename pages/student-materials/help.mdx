# Помощь

## CSS не подключился

Проверь строку `<link rel="stylesheet" href="style.css">` внутри `head`.

## Забыл сохранить файл

Нажми `Ctrl+S` / `Cmd+S` и обнови страницу.

## Неправильное название `style.css`

Имя должно совпадать буква в букву: `style.css`.

## `index.html` и `style.css` лежат в разных папках

На первом уроке держи файлы в одной папке.

## Забыл точку перед `class` в CSS

Если в HTML `class="card"`, в CSS нужно писать `.card`.

## Изменения не видны в браузере

Сделай принудительное обновление страницы: `Ctrl+F5` / `Cmd+Shift+R`.

## Текст съехал

Проверь незакрытые теги и лишние фигурные скобки в CSS.

## Кнопка не центрируется

Проверь у кнопки:

```css
display: inline-flex;
align-items: center;
justify-content: center;
```
