# Домашнее задание

**Задание:** сделать карточку для себя или вымышленного персонажа.

## Требования

- Заголовок.
- Описание.
- Аватар.
- Кнопка.
- Свой цвет фона.
- Аккуратные отступы.
- CSS подключён отдельным файлом.

## Критерии проверки

- Файл называется `index.html`.
- CSS подключён правильно.
- Карточка находится по центру.
- Текст читаемый.
- Кнопка выглядит как кнопка.
- Код отформатирован.
