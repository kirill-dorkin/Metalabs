## Уроки

1. Git, GitHub, Cursor — создаёт репозиторий и работает с AI-редактором.
2. TypeScript основы — понимает типы, интерфейсы, ошибки типов.
3. React и компоненты — создаёт первый компонент.
4. Props — передаёт данные в компоненты.
5. State и events — делает интерактивные элементы.
6. Списки и формы — рендерит массивы и управляет input.
7. useEffect — загружает данные при открытии страницы.
8. API в React — подключает frontend к API.
9. Роутинг — делает несколько страниц.
10. UI-компоненты — собирает интерфейс из переиспользуемых блоков.
11. Работа с AI — использует Cursor/Claude для объяснения, рефакторинга и поиска ошибок.
12. Мини-проект и экзамен — делает React-приложение.
