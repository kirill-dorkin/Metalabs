## Уроки

1. Linux и терминал — уверенно выполняет базовые команды.
2. Файлы, процессы, права — понимает `cd`, `ls`, `chmod`, процессы.
3. SSH и VPS — подключается к серверу.
4. Nginx — настраивает reverse proxy.
5. Docker basics — понимает image/container.
6. Docker Compose — запускает app + db.
7. ENV и secrets — настраивает переменные окружения.
8. PostgreSQL в Docker — поднимает базу и делает backup.
9. GitHub Actions — настраивает простой CI/CD-процесс.
10. Domain и SSL — подключает домен и HTTPS.
11. Logs и monitoring — читает логи и ищет ошибки.
12. Мини-проект и экзамен — деплоит fullstack-приложение.
