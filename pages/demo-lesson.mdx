# Демо-урок: HTML и CSS с нуля

<p className="lead">Первое занятие для учеников без IT-опыта. Без терминала, Git, npm и фреймворков.</p>

## Тайминг урока (1.5 часа)

### 0–10 минут

Приветствие и цель урока.

Что говорю:

"Сегодня мы не будем начинать со сложных инструментов. Наша цель — понять самую базовую связь: файл → браузер → страница."

### 10–20 минут

Что такое сайт.

Сайт — это набор файлов. Браузер читает эти файлы и показывает результат.

### 20–30 минут

HTML и CSS простыми словами.

HTML — смысл и содержимое. CSS — внешний вид.

### 30–40 минут

Создаём папку проекта:

```txt
my-first-site/
  index.html
  style.css
```

### 40–55 минут

Создаём первый `index.html`:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Моя первая страница</title>
  </head>
  <body>
    <h1>Привет!</h1>
    <p>Это моя первая веб-страница.</p>
  </body>
</html>
```

### 55–65 минут

Открываем файл в браузере. Это уже первая веб-страница.

### 65–75 минут

Подключаем `style.css`:

```html
<link rel="stylesheet" href="style.css">
```

### 75–85 минут

Добавляем первые стили:

```css
body {
  background: #f5f7fb;
  font-family: Arial, sans-serif;
  color: #1f2937;
}

h1 {
  color: #2563eb;
}
```

### 85–90 минут

Итог урока, домашнее задание и ссылка на материалы.
